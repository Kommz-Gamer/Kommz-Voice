# Contribuer

Merci de vouloir contribuer a **Kommz Voice**.

## Avant de commencer

- Lis `README.md` et `SECURITY.md`.
- Ne commit **jamais** de secrets (API keys, tokens, fichiers `.env`, `settings.json`).
- Utilise `env.template` et `settings.example.json` pour la configuration.

## Signaler un bug

Ouvre une issue avec :

- OS + version Python
- Commande de lancement
- Logs (extrait court) + erreurs exactes
- Etapes de reproduction
- Comportement attendu vs observe

## Proposer une evolution

Explique :

- le besoin (cas d'usage)
- l'impact attendu
- une proposition d'API / UI si c'est cote client

## Pull Requests

- Une PR = un sujet.
- Ajoute une description claire, des tests si possible, et des notes de compatibilite.
- Si tu touches a l'API, documente les changements dans `README.md` et/ou `docs/`.

## Style / hygiene

- Preferer du code lisible et des erreurs explicites.
- Eviter les gros fichiers de debug, artefacts et dumps dans Git.
